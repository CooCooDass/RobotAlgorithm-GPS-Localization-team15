# 1주차 · 환경 설정과 배경 지식

Python 3.10 이상과 Git이 필요합니다. 하드웨어 실습에는 Arduino IDE 2.x를 준비합니다. 아래 환경 점검에는 외부 Python 패키지나 Arduino 연결이 필요 없습니다.

```sh
git clone https://github.com/CooCooDass/RobotAlgorithm-GPS-Localization-team15.git
cd RobotAlgorithm-GPS-Localization-team15
python week1/src/check_environment.py
```

비공개 저장소이므로 접근 권한이 있는 GitHub 계정으로 인증합니다. 실행하면 Python 버전과 운영체제가 출력됩니다. Python 3.10 이상이면 `Python environment check passed.`가 표시됩니다. 환경 점검 스크립트에는 조정할 하이퍼파라미터가 없습니다.

[1주차 보고서 초안](reports/team15_week1.pdf)에 Git 실습과 배경 지식 6문항을 정리했습니다. 제출 전에 실제 수업에서 다룬 알고리즘과 팀원별 실습 내용을 확인해 반영합니다.
